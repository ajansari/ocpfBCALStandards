# Changelog

OCPF AL Development Standards Guide, by AJ Ansari and OnlyCopilotFans.

All notable changes to the OCPF AL Development Standards Guide are recorded here. Consumers pin a release tag; the tag name matches the `Version` line in the guide's header.

The guide was previously maintained inside the OnlyCopilotFans BC Agentic Dev Framework, where its history up to and including version 1.11.0.0 (September 27, 2026) is recorded. From this repository on, all changes to the guide are logged here.

## [Unreleased]

### Changed
- Guide moved to its own repository as the single source of truth. Consumers fetch it at a pinned tag instead of carrying a copy.
- Preamble rewritten for a standalone audience: process-specific references removed; the authoritative-source rule now refers generically to the project's own parameter sheet.
- Added `README.md`, `CONTRIBUTING.md` (append-only numbering, citation requirement), and `docs/ComparisonWithALGuidelines.md`.

### Unchanged
- Every Part, section, and appendix keeps its existing number. Citations of the form *Standards §X.Y* written against version 1.11.0.0 remain valid.
